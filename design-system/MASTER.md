# Aimo Trust Gateway UI

Workflow application; customer tasks take precedence over operational detail.

- Valio Aimo wordmark from its public website; preserve its proportions and clear space.
- Brand petrol #005670, dark petrol #003747, pale blue #f2f7f8, border #d1dde3, and lime #c0e021 (hover #abc80b), based on the public Valio Aimo site. Use dark text on lime actions.
- Inter for readable interface text and Arial for headings as local substitutes: the public site uses Matter and National, whose redistribution rights were not verified.
- 8px spacing rhythm; restrained surfaces, 44px minimum primary controls.
- Fixed desktop sidebar, compact horizontal navigation on small screens. One primary action for each screen state.
- Customer sees basket, reason and decision. Aimo sees execution timeline and tool evidence.
- Support keyboard navigation, visible focus, status announcements, 375px width and reduced motion.
