# Aimo Trust Gateway UI

Workflow application; customer tasks take precedence over operational detail.

- Light background #F6F8FA; surface white; foreground #142D45; muted text #536477.
- Primary action #175CD3, hover #124AA9, white text. Success emerald, pending amber, failure red, each paired with text/icon.
- Inter, 15–16px body, 28–34px headings, tabular figures for prices and quantities.
- 8px spacing rhythm; 14px panel corners, 8px controls, 44px minimum primary controls.
- Fixed 224px sidebar on desktop, compact horizontal navigation on small screens.
- One primary action for each screen state. Data provenance and alternatives expand on demand.
- Customer sees basket, reason and decision. Aimo sees execution timeline and tool evidence.
- No decorative raster assets, analytics charts, raw model reasoning or fabricated live progress.
- Support keyboard navigation, visible focus, status announcements, 375px width and reduced motion.

Based on ui-ux-pro-max's minimal enterprise/workflow guidance. The generic marketing hero and unrelated disclosure search results were not used as workflow guidance.
